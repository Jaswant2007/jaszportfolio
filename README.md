# Premium Dev Portfolio

PREMIUM DEVELOPER PORTFOLIO — WEBSITE CREATION PROMPT

1. Website Goal

Create a premium, modern and highly interactive personal developer portfolio.

It should look like a top-level professional portfolio, not a basic student website.

2. Theme & Design

Use a strictly light theme with white/off-white backgrounds and dark text.

Add gradient blurs, soft shadows, glass effects, smooth transitions and modern typography.

3. Technology Stack

Strictly use HTML, CSS, JavaScript, Framer Motion, Three.js (3JS) and Particle.js.

Do not use unnecessary frameworks or libraries outside this stack.

4. Overall Animation

Make the website heavily animated with smooth and premium animations.

Use scroll animations, hover effects, parallax, text reveals, scaling and smooth micro-interactions.

5. 3D Animations

Use Three.js for interactive 3D elements, especially in the Hero and Projects sections.

3D objects should react smoothly to mouse movement without affecting performance.

6. Particle Background

Use Particle.js for interactive particle backgrounds.

Particles should react subtly to the mouse and automatically reduce on mobile.

7. Navigation

Create a clean floating navigation bar with links to all major sections/pages.

Include Home, About, Projects, Skills, Articles and Contact.

8. Page Transitions

Every page should transition seamlessly into the next with a full-page animated transition.

Give different pages slightly different transition styles while maintaining the same design language.

9. Home / Hero Section

Create a visually impressive Hero section with my name, introduction, role and short personal tagline.

Add strong CTAs such as View Projects and Let's Connect with animated buttons.

10. About Section

Add a detailed but clean introduction about me.

Include my academic background, current education, interests and what I am currently learning.

11. Academic Information

Create a dedicated area for my academic details and educational journey.

Use an animated timeline or modern cards to present education clearly.

12. Currently Learning

Show the technologies, concepts and subjects I am currently learning.

Use interactive cards or animated visual elements instead of boring lists.

13. Certificates

Add a section for my certificates and achievements.

Each certificate should have its title, organization, date and optional credential/view link.

14. Projects Section

Create a highly interactive and visually impressive Projects section.

Display project image, title, description, technologies, GitHub link and live-demo link.

15. 3D Project Cards

Add a 3D hover effect to project cards using Three.js/CSS/JavaScript.

Cards should tilt, move and respond smoothly to the user's cursor.

16. Project Categories

Allow projects to be filtered by categories such as Web, AI/ML, C, Java, Hardware and others.

Filtering should happen with smooth animations.

17. Skills Section

Create an interactive Skills section covering programming, web development, AI/ML and tools.

Use animated cards, floating elements or interactive technology nodes instead of simple percentage bars.

18. Coding Profiles

Add dedicated links/cards for my coding profiles.

Include LeetCode, GitHub, GeeksforGeeks, CodeChef, HackerRank, Codeforces or any profiles I provide.

19. GitHub

Add a prominent GitHub profile section with a link to my profile.

Allow featured repositories/projects to be displayed.

20. LeetCode

Add a dedicated LeetCode profile card.

Allow statistics such as problems solved, streak or ranking to be added later without creating fake data.

21. Articles Section

Create a modern Articles/Blog section for my technical articles.

Each article should show title, description, category, date, reading time, tags and a Read Article button.

22. Social Links

Include my important social links such as LinkedIn and GitHub.

Add animated icons with smooth hover effects and tooltips.

23. Contact / Email

Create a dedicated Contact page where visitors can contact me.

Include Name, Email, Subject and Message fields with proper validation.

24. Email Functionality

Add a working method to send an email/message to me.

Do not expose private API keys and provide a configurable email solution or mailto fallback.

25. Call-to-Action

Use attractive CTAs throughout the website.

Include buttons such as View Projects, Let's Connect, View GitHub, Read Articles and Contact Me.

26. Gradient Backgrounds

Add large soft gradient-blurred shapes throughout the website.

Animate them slowly in the background to create depth without distracting from content.

27. Custom Cursor

Add a subtle animated custom cursor on desktop.

Disable it automatically on mobile and touch devices.

28. Scroll Animations

Use smooth scroll-based animations for sections, cards, images and text.

Include fade, slide, reveal, parallax and scale effects.

29. Mobile Compatibility

Make the entire website fully responsive for mobile, tablet and desktop.

Replace hover-based interactions with touch-friendly interactions on mobile.

30. Mobile Performance

Reduce particle density, 3D complexity and heavy animations on smaller devices.

Ensure the website remains smooth and fast on mobile.

31. Accessibility

Use semantic HTML, proper labels, keyboard navigation and readable contrast.

Support prefers-reduced-motion for users who want fewer animations.

32. Footer

Create a clean premium footer containing my name, short tagline, navigation, LinkedIn, GitHub, coding profiles and email.

Add a subtle final animation when the footer enters the viewport.

33. Content Management

Keep personal information, projects, skills, certificates, articles and social links easy to edit.

Store these details in a centralized JavaScript data/configuration section.

34. Performance

Keep animations smooth and optimized while maintaining the heavy visual experience.

Avoid unnecessary effects, memory leaks, console errors and slow loading.

35. Final Quality

The final website should feel premium, futuristic, creative, professional and highly interactive.

It should impress recruiters, developers and clients while remaining clean and easy to navigate.

36. Final Requirement

Build the complete functional website, not just a UI mockup.

Ensure all pages, navigation, animations, 3D effects, particles, project links, social links and contact functionality work correctly.
